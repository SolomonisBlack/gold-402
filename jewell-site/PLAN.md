## Conversion features
- Click-to-call and click-to-text everywhere, plus a sticky mobile bar (Call · Text · Free Estimate)
- Short quote form above the fold on the home page (name, phone, service, ZIP) and a full form on the contact page, plus a "Get a Free Estimate" call to action on every page
- Trust signals near every call to action (licensed and insured, 1-year warranty, price match, family owned)
- Offers shown clearly: 10% off for single mothers, price match
- Real photos first; licensed stock photos (Unsplash or Pexels license) only where Jewell has none
- No fake reviews: a review section links to their real Facebook page until real testimonials are collected

## Technical
- Plain HTML, CSS, and JS generated by a small Python build script (one shared header, footer, and design system). No framework lock-in, so it is fast and uploads easily to Hostinger.
- SEO: unique titles and meta descriptions, LocalBusiness/HomeAndConstructionBusiness JSON-LD, FAQ schema, sitemap.xml, robots.txt, Open Graph tags
- Performance: resized WebP and JPEG images, lazy loading, a single CSS file and a single small JS file
- Accessibility: semantic HTML, contrast-checked brand colors, keyboard navigation and focus states, alt text
- Forms: a `send.php` handler that works on Hostinger, with a honeypot field for spam protection, and a fallback that opens the visitor's email or texting app

## Process
1. Build → 2. Devil's-advocate review (conversion, trust, mobile, SEO, accessibility, code) → 3. Fix everything found → 4. Deploy for review → 5. Hand over link + open items
